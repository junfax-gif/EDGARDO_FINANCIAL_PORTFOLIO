Cloud sync & account

Connect your Supabase project to access your portfolio across devices.

Not connected

1. Connect your Supabase project

Use your project URL and publishable (or legacy anon) key.

Find these values in your Supabase project dashboard under Connect or Project Settings → API Keys. Never use a service_role or secret key here.

2. Create an account or sign in

Use an email and a strong password to keep your portfolio private.

Cloud sync is not configured. Save your Supabase settings first, then create an account or sign in.

Before your first sync

  • Run the supplied Supabase SQL setup script in your project's SQL Editor.
  • Download a JSON backup from Reports & Backup before connecting existing records.
  • When a new account has no cloud portfolio, the app uploads the data currently stored in this browser.
  • To use this website on multiple devices, open the same hosted URL and sign in to the same account.
